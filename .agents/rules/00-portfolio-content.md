# Portfolio content rules

This repo is a **portfolio for DevOps / Virtualization / Platform engineering roles**, not a dump
of notes. Every change must make a recruiter's read faster or a claim stronger.

1. **Evidence over adjectives.** If a sentence has "significantly", "robust", "cutting-edge", it
   must also have a number, a tool name, or a link. Otherwise delete the adjective.
2. **Never invent.** No fabricated employers, dates, metrics, certifications, or technologies.
   If information is missing, leave a `<!-- TODO: ... -->` marker and say so.
3. **Bilingual contract.** `README.md` carries both English and Vietnamese content; CV has an EN
   and a VI edition. Update both or neither — never let one lag behind.
4. **Structure is stable.** Do not reorder top-level README sections or rename the Skills Matrix
   categories without being asked.
5. **Diagrams are Mermaid.** No screenshots of architecture when a `graph TD` is possible.
6. **Public-facing tone.** No internal IPs beyond RFC1918 examples already published, no customer
   names, no credentials, no internal hostnames from real employers.
